# Product

## Platform

web

## Users

Exactly one primary target segment:
- Solo/freelance digital designers who need fast, defensible visual brief directions to align client expectations on strategic design parameters before executing wireframes or visual assets.

## Product Purpose

Gamut is a deterministic tradeoffs compiler that resolves brand strategy questions into a structured, production-ready System Direction Brief. By forcing forced-choice answers on category context, position, temperament, stance, volume, age, and core, it computes mathematical color theory, contrast ratios, and typography pairings. Decisions are defined by both positive strategic rationales and explicit negative constraints (ruled-out design paths). Spacing, radius, elevation, and component state tokens are compiled from the same archetype settings, allowing designers to export system assets directly to CSS, Tailwind, or JSON, or print the brief to a clean A4 portrait PDF presentation.

## Positioning

Unlike random generators (e.g. Coolors, Huemint) that rely on endless shuffling, Gamut compiles systems based on structured tradeoffs and rules. Decisions are entirely defensible, backed by WCAG contrast compliance and color psychology. There is no guesswork or black-box model involved; the compiler is transparent, deterministic, and immediate.

## Operating Context

Runs as a client-side static site (HTML/CSS/JS, no build step, no framework, no backend) that can be opened as a local file or served statically. It operates fully offline with zero network calls except dynamically loading the curated type specimen fonts from Google Fonts.

## Capabilities and Constraints

- No user accounts or external databases. State is fully shareable via URL query parameters.
- Token export (`gamut.tokens.v1`) is structured to act as seed data for external consumers (e.g., Design OS's Change Impact Engine).
- Google Fonts load dynamically based on the compiled mood parameters.

## Brand Commitments

Site aesthetics are locked to the **Museum Editorial** system (flat, monochrome-leaning, shadow-free chrome) styled in Combo 06 (Lime/Charcoal/Bone). All colored content is generated by the engine's live compiled outputs.

## Evidence on Hand

None yet. No real usage data, user feedback, or testimonials exist. "Evidence on Hand: None yet" remains true.

## Product Principles

1. **Strategic floor, deterministic results:** Contrast ratios and design system token mappings are hardcoded rules. Answers yield deterministic, stable briefs with no temporal random drift.
2. **Defensible constraints:** The compiler defines design directions as much by what is ruled out as by what is selected.
3. **Cohesive systems, not just colors:** Corners, shadows, spacing density, and state values are generated as a unified system from the strategic tradeoffs.
4. **Honest and open:** The product does not hide its constraints or naively over-claim compliance; it provides transparent verification readouts.
