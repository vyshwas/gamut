## Platform

web

## Users

Two unprioritized segments, both served by the same tool:
- Solo/freelance designers who need fast, defensible palette and type-pairing decisions without a color-theory deep dive.
- Small agencies and in-house brand teams producing multiple client identities who need consistent, law-based output across projects.

No primary segment has been chosen yet; the Studio (solo) / Agency (team) pricing split in the README reflects this open question rather than a resolved decision.

## Product Purpose

Gamut generates brand color palettes, fixes existing broken palettes, and pairs typography — derived from The Brand Color Bible v2 methodology (60-30-10 rule, ten laws of color, nine psychology profiles), with a taste layer on top: within a category's law-compliant range, seed and a curated set of color-harmony choices (the category's own pairing, or a complementary/split-complementary/triadic alternative rolled from the brand hue) drive genuine hue variety instead of one narrow "safe" answer per category. The laws are the floor (contrast, the 60-30-10 ratio, Law 2's saturation relationship) — never bypassed; taste decides which law-compliant result you get. It also generates the rest of a matched design system (spacing, radius, elevation, component states) from the same archetype signal as the colors, and exports everything as CSS/Tailwind/SCSS/JSON. Success means a user leaves with a complete, law-compliant, contrast-safe, print-and-digital-ready design system they can paste directly into a project.

## Positioning

Every output is checked against named, explicit rules (the ten laws) and contrast/print constraints, and violations are diagnosed by name — not generated by an opaque model or random palette shuffler the way Coolors, Khroma, or Huemint work. The Fixer specifically distinguishes Gamut from pure-generator competitors: it takes an existing broken palette and repairs it against the same law set, showing before/after and which law caused each change. The Studio Assistant's LLM layer is constrained to interpret briefs only onto Gamut's own fixed frameworks (mood lexicon, business archetypes) and never invents hex codes — a hallucinated value is dropped, not shipped.

## Operating Context

Runs as a static site (plain HTML/CSS/JS, no build step, no framework, no backend) — can be opened directly as a file or served statically. The Studio Assistant's local (Ollama) and Claude API providers require serving over `http://` rather than `file://` due to browser CORS behavior; an offline keyword-match fallback always works with no network call. Currently deployed live at vyshwas.github.io/gamut/ (GitHub Pages).

## Capabilities and Constraints

- No backend and no accounts exist yet. Feature gating for paid tiers is explicitly not implemented — the demo runs fully unlocked.
- Pricing ($0/$12/$49 Free/Studio/Agency) is a placeholder anchor, not validated or finalized.
- CMYK conversion is a naive uncoated approximation, honestly labeled in the UI — not an ICC-accurate pipeline.
- All ten business archetypes and the mood lexicon are code-owned, fixed vocabularies; the LLM assistant layer never operates outside them.
- Structured token export (`gamut.tokens.v1`) is also consumed as seed data by a separate project (Design OS's Change Impact Engine) — Gamut and that project stay independent codebases with no merge.

## Product Principles

1. Law-based floor, taste-based variety: contrast, the 60-30-10 ratio, and Law 2's saturation relationship are never bypassed — but which law-compliant hue, harmony, and accent pairing a given generation lands on is a taste decision (curated per-category recipe vs. a complementary/triadic alternative), not a single deterministic "correct" answer per category. Changed 2026-07-25: the product was previously law-based only; the user explicitly asked for taste-driven variety on top of the same law floor.
2. Never fabricate: the LLM assistant layer only maps onto real, code-owned vocabularies; hallucinated values are dropped, not shipped.
3. Full system, not just color: spacing, radius, elevation, and states are derived from the same per-archetype signal as color, not bolted on separately.
4. Honest about approximation: any heuristic (CMYK conversion, print-safety flags) is explicitly labeled as such rather than presented as authoritative.
5. Tools stay independent: Gamut is a standalone product; it may feed structured data to other projects (e.g. Design OS) but does not merge codebases or product identity with them.
